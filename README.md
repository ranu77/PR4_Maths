# 🧮 Calculative Foundation

## 📌 Project Overview

**Calculative Foundation** is a practical Linear Algebra project focused on applying mathematical concepts to a student performance dataset.

The project demonstrates how **vectors, matrices, norms, dot products, projections, geometric concepts, covariance matrices, eigenvalues, and eigenvectors** can be applied to real-world data analysis.

These concepts form an important mathematical foundation for **Data Science, Artificial Intelligence, Machine Learning, and Engineering**.

---

## 🎯 Objectives

The main objectives of this project are to:

* Represent student performance data using vectors and matrices.
* Perform fundamental vector operations.
* Calculate L1 and L2 norms.
* Calculate dot products and angles between vectors.
* Perform cross products and vector projections.
* Perform matrix addition and multiplication.
* Calculate matrix transpose, inverse, and determinant.
* Understand lines, planes, and hyperplanes.
* Construct and analyze covariance matrices.
* Calculate eigenvalues and eigenvectors.
* Understand variance explained by eigenvalues.

## 🔢 Key Mathematical Concepts

### Vector Norm

The **L1 norm** measures the sum of the absolute values of vector elements.

The **L2 norm** represents the Euclidean length of a vector.

### Dot Product

The dot product measures the relationship between two vectors and is used to calculate the angle between them.

### Cross Product

The cross product produces a vector perpendicular to two three-dimensional vectors.

### Vector Projection

Projection determines the component of one vector along another vector.

### Matrix

A matrix provides a structured representation of student scores across multiple subjects.

### Covariance Matrix

The covariance matrix describes how different subject scores vary together.

### Eigenvalues & Eigenvectors

Eigenvalues indicate the amount of variance represented along corresponding eigenvector directions.

These concepts are particularly important in **Principal Component Analysis (PCA)** and dimensionality reduction.
